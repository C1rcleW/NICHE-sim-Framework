## 0.1.2：工程稳定性发布

本版聚焦可验证性与结果可信度：修复生境坐标错误、运行结果串用、拟合结果上下文错配、
输入与 ML 特征边界，并新增真实浏览器与 CI 门禁。

**本版不改变影响公式、经济压力、收入归一化或默认模型参数。** 相关研究语义问题记录在
[R0 研究决策记录](R0-研究决策记录.md)，等待明确决策。

## 主要修复

- **生境坐标可信化**：`/api/niche` 输出原始值、缺失维度和截断维度；缺失的
  `social_capital` 返回 `null`，并修复维度键映射错误导致所有有效坐标退回 0.5。
- **运行隔离**：每次运行生成 `run_id` 与不可变快照；查询、拟合、生境和网络均绑定
  同一运行，旧运行请求返回结构化 404。
- **输入契约**：参数规格成为单一真源；未知/越界参数、未知成员字段、空运行和超量请求
  在 422 层拒绝。
- **拟合可信度**：新增每状态 R²/RMSE/样本数；拟合结果绑定成员、模型和运行上下文；
  切换上下文即作废旧结果；运行中禁止用空 `run_id` 拟合。
- **前端可靠性**：成员名与家庭名使用文本渲染；Run/Fit 期间禁用按钮；语言切换后
  状态栏、家庭名、拟合结果、模型后缀和网络图保持正确。
- **ML 接口**：目标列不进入特征；自动特征避开目标行缺失的跨类型列；过滤 NaN/Inf；
  新增可追溯监督表、含标签 purge 的时间切分和按时间截断的网络特征。
- **交付**：Playwright Chromium 冒烟测试、Node 前端 job、PEP 440 版本门禁、
  当前版本 Web 截图与实验图引用。

## R0：待决研究问题

R0 记录以下事项的当前实现事实与变更门槛：

- 影响公式中的来源归一化与未成年成员分摊；
- 家庭经济压力的步内时序、首步压力与收入基准；
- 生境经济维度的收入归一化；
- 成年成员易感性记录与 E2 成年期结果的解释；
- `Simulation.reset()` 语义；
- `resource_competition` 默认参数边界的病态行为。

在 R0 签署前，不得把上述差异描述为“已修复”或“已确认”。任何模型行为变更必须重跑
基线、E1–E4、敏感性分析、可约性实验，并同步研究设计文档与实验数据表。

## 安装

下载 Release 附件中的 wheel 后：

```bash
pip install family_abm-0.1.2-py3-none-any.whl
python -m family_abm.web      # http://127.0.0.1:8520
```

要求 Python >= 3.10；MIT 许可。

已知限制见 [README 的说明与限制](https://github.com/C1rcleW/NICHE-sim-Framework#说明与限制)。
